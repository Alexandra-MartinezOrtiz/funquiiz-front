# Funquiiz — Frontend

Aplicación web frontend desarrollada con **React**.

## Tecnologías verificadas

Según `package.json`:

- React 18 y React DOM
- React Router DOM 6
- React Icons
- Create React App (`react-scripts` 5)

## Desarrollo local

Con Node.js y npm instalados:

```bash
npm install
npm start
```

## Scripts disponibles

| Comando | Función |
| --- | --- |
| `npm start` | Iniciar servidor de desarrollo |
| `npm run build` | Generar compilación de producción |
| `npm test` | Ejecutar pruebas configuradas |
